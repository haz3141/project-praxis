# Versioning

## Version 1.0
## Status: Foundational
## Last Updated: 2026-03-01

## Documentation Version Model

- Constitutional docs use explicit metadata headings for version, status, and last updated date.
- Major version increments indicate structural or semantic constitutional change.
- Minor version increments indicate additive clarification without semantic drift.
- Patch version increments indicate non-semantic correction.

## Code Version Model

- Application versioning follows semantic versioning when runtime code is introduced.
- Documentation and code versions may progress independently, but constitutional major changes require ADR linkage.
