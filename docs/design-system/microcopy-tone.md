# Microcopy Tone

## Voice
- Clear, direct, and calm.
- Supportive but not sentimental.
- Action-oriented and specific.

## Principles
- Lead with the action and expected outcome.
- Use plain words over jargon.
- Keep helper text short and task-relevant.
- Use error text that explains recovery, not blame.

## Button Labels
- Prefer verb-first labels: `Save changes`, `Create goal`, `Close`.
- Avoid vague labels like `Submit` unless context is explicit.

## Helper Text
- Keep to one sentence.
- Explain constraints only when needed.

## Error Messages
- Structure: what happened + how to fix it.
- Example: `Name is required. Enter a name to continue.`
- Avoid all-caps, sarcasm, or passive-aggressive tone.

## Empty and Success States
- Empty: explain next best action.
- Success: confirm outcome briefly and move on.
